## How to Run
Prerequisites
- Have a C++ compiler installed on your device (MSVC/Clang/GCC)
- Ensure you are in the right working directory

Compile with:
`g++ -std=c++20 *.cpp -o main`
or
`g++ -std=c++20 Auth.cpp Billing.cpp Booking.cpp Customer.cpp Feedback.cpp main.cpp Utils.cpp Voucher.cpp -o main`

Run with:
`./main` or `./main.exe`
